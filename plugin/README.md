# esp-architecture plugin

The shipped Claude Code plugin: skills, hooks and the checker that make an ESP-IDF project's architecture code. It reads the project's `arch/architecture.yaml`, enforces the allowed dependencies between components, requires backed decisions, and generates context, block, organigram and layering diagrams.
